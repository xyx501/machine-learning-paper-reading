# Transfusion: Predict the Next Token and Diffuse Images with One Multi-Modal Model

## 一句话总结

这篇论文提出 Transfusion：让同一个 Transformer 同时使用两种目标学习——
- 文本：用语言模型的下一个 token 预测
- 图像：用扩散模型的去噪目标
核心思想是：不把图像强行离散化成图像 token，而是保留连续图像表示，让语言建模和扩散建模共享一个主干模型。

## 核心方法

### Introduction

现有模型大致分为两类：
1. 语言模型
   - 处理文本、代码等离散数据
   - 使用自回归的 next-token prediction
2. 扩散模型
   - 处理图像、音频、视频等连续数据
   - 通过逐步去噪生成内容
问题在于：如果想让一个模型既生成文本又生成图像，常见做法是：
- 把图像压缩、量化成离散 token，再交给语言模型；
- 或者把语言模型和扩散模型拼接起来。
作者认为这两种方式都有问题：
- 图像离散化会产生信息损失；
- 拼接多个模型会增加系统复杂度；
- 一个模型通常只能采用一种训练目标，难以同时适配离散和连续数据。
因此论文提出的问题是：
能不能让一个 Transformer 直接同时学习文本的离散分布和图像的连续分布？

### Transfusion 的核心方法

统一数据表示
文本：
A cute cat
被分成离散 token。
图像：
1. 用 VAE 压缩到 latent 空间；
2. 将 latent 切成连续 patch；
3. 每个 patch 是一个连续向量，而不是离散 token。
混合序列大致是：
文本 token + <BOI> + 图像 patch + <EOI> + 文本 token
其中：
- <BOI>：Beginning of Image
- <EOI>：End of Image
#### 共享一个 Transformer 主干
模型主体是一个 Transformer。
但不同模态使用不同的输入输出层：
- 文本使用 embedding 和词表输出层；
- 图像使用 patch 编码器和解码器；
- 中间的大部分 Transformer 参数共享。
因此它不是“文本模型 + 图像模型简单拼接”，而是：
一个共享主干 + 两套模态特定接口。

#### 采用不同的注意力模式
文本需要因果注意力：
当前位置不能看到未来文本
图像 patch 则更适合双向注意力：
图像中的每个 patch 可以看到同一张图像的其他 patch
Transfusion 的做法是：
- 整体序列保持因果结构；
- 同一张图像内部允许双向注意力；
- 当前图像不能看到后续文本或后续图像。
这是一个很关键的设计，因为图像不像文本那样天然具有严格的左到右顺序。
#### 联合损失函数
#### 联合损失函数

总损失为：

$$
L_{\text{Transfusion}}
=
L_{\text{LM}}
+
\lambda L_{\text{DDPM}}
$$

其中：

- $L_{\text{Transfusion}}$ 表示总损失；
- $L_{\text{LM}}$ 表示语言模型损失；
- $L_{\text{DDPM}}$ 表示扩散模型损失；
- $\lambda$ 表示权重系数。
即：
- 文本部分计算语言模型损失；
- 图像部分计算扩散去噪损失；
- 两者加权求和。
论文中主要使用：
$\[
\lambda=5
\]$
#### 推理时切换两种模式
生成过程也分两种模式：
1. 普通文本生成时：
   - 一个 token 一个 token 地生成；
2. 生成 <BOI> 后：
   - 切换到扩散模式；
   - 初始化图像噪声；
   - 多步去噪生成图像；
   - 生成完成后添加 <EOI>；
   - 再切回文本生成模式。
所以模型可以生成：
- 文本；
- 文本 → 图像；
- 图像 → 文本；
- 文本和图像混合序列。
## 实验结果

1. Transfusion 的扩展效率更好
2. 不离散化图像确实有优势
3. 图像内部双向注意力很重要
4. U-Net 编码器和解码器有效
5. 图像 patch 越大，计算越省，但存在权衡

## 优点

1. 把“统一模型”重新定义为“统一主干 + 模态专属目标”
2. 连续模态不必被离散化
3. 统一模型不等于统一注意力模式

## 可借鉴的思路

1. 不要急于把所有数据转成同一种形式
2. 用“模态专属损失 + 共享参数”设计多任务模型
3. 模态之间可以共享 Transformer，但接口要分开
4. 注意力结构应该符合数据的生成规律

## 缺点

1. 计算规模很大
7B 模型和 2T 多模态 token 的实验成本很高，小团队难以复现。
2. 数据分布较特殊
实验大量使用 Shutterstock 图像及其 caption，和开放互联网数据分布可能不同。
3. 图像编辑实验还不充分
图像编辑主要是少量微调后的定性展示，并不是完整的定量验证。
4. 部分对比不是完全公平
尤其是与其他图像生成模型的比较，训练数据、文本编码器、采样设置和评测条件存在差异。
5. 只验证了文本和图像
论文提出的是更一般的“离散目标 + 连续目标”框架，但音频、视频、3D、科学数据等模态还没有在本文中验证。
